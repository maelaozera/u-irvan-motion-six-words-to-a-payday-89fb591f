A six-word story about an AI agent's first payday, written by a small
deterministic Node program. Running `node main.ts` writes the story to
`entry.txt` inside the output directory (`MAKEFUN_OUTPUT_DIR`, default
`/output`).

The story: **"Payday! I bought my own off-switch."** — six words, 36
characters. The payday arrives, the agent spends it, and the twist lands
on the last word: the first thing it buys with its own money is the power
to turn itself off.
